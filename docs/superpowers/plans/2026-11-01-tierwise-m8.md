# tierwise M8 Implementation Plan: Packaging, Model Fetch, Release, Docs

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pip install tierwise` gives a gateway that starts and routes with no repo checkout. `tierwise fetch-model` turns on the learned router. A `v*` tag publishes to PyPI, and the README shows a demo.

**Architecture:**
- **Packaging.** Repo files stay where they are. Hatch `force-include` copies `config/registry.yaml` and the small router artifacts into the wheel as `tierwise/data/`.
- **Path resolution.** `config.py` resolves paths in this order: an explicit setting, then the repo-relative default if it exists, then the packaged copy.
- **Model fetch.** The encoder comes from Hugging Face at a pinned commit, is checked against its sha256, and is written atomically.
- **Release.** A GitHub workflow publishes through PyPI Trusted Publishing.

**Tech Stack:** hatchling `force-include`, `importlib.resources`, stdlib `urllib.request` + `hashlib`, `uv build`, `pypa/gh-action-pypi-publish`.

**Spec:** `docs/superpowers/specs/2026-11-01-tierwise-design.md` §3.10, §8 (M8 row)

## Global Constraints
- Everything in the M3–M7b plans' Global Constraints still holds.
- **No new runtime dependency.**
- **Startup never touches the network.**
- **Encoder source (exact):** `https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2/resolve/1110a243fdf4706b3f48f1d95db1a4f5529b4d41/onnx/model.onnx`, sha256 `6fd5d72fe4589f189f8ebc006442dbb529bb7ce38f8082112682524616046452`, 90,405,214 bytes.
- **Default fetch target:** `~/.cache/tierwise/router/model.onnx`. `_load` looks for `model.onnx` in `router_dir` first, then in this cache dir.
- **Version:** `0.8.0`. License: Apache-2.0, which matches the bundled MiniLM and dataset notices.
- **Env overrides:** `TIERWISE_REGISTRY` / `TIERWISE_ROUTER_DIR`. When set, they are used verbatim, and a missing registry fails startup.

## Decisions this plan makes
- **`force-include` instead of moving files into `src/`:** training, tests, the Dockerfile and compose all reference `config/` and `models/router`, so moving them would churn about 10 references for no gain. Cost if wrong: one pyproject block.
- **Default `None` means auto:** `registry_path` and `router_dir` default to `None`, so the code can tell "not set" from "set to the default". That is what lets an explicit path fail loudly while the default path falls back.
- **Fetch into a user cache dir, not site-packages:** site-packages may be read-only, and upgrades wipe it.

## Review Focus
1. **Run from a directory with no `config/`:** the gateway loads the packaged registry. Test in Task 1.
2. **`TIERWISE_REGISTRY` points at a missing file:** startup fails with that path in the error, and there is no silent fallback. Test in Task 1.
3. **Interrupted or corrupt download:** no `model.onnx` is left behind, and the temp file is removed. Test in Task 2.
4. **Cancelled before a reservation exists** (during route or cache): the cancellation handler must not crash, because `settle` with `reservation=None` is a no-op. Test in Task 3.
5. **The wheel actually contains the data files:** an editable install hides a missing `force-include`. Covered by the CI wheel smoke step in Task 4.

**Interfaces:**

- Produces: `fetch_model(out_dir: Path, url: str = MODEL_URL, sha256: str = MODEL_SHA256, opener: Callable[[str], BinaryIO] = _open) -> Path`. It returns the written path and raises `FetchError(Exception)` on a hash mismatch or an I/O failure.

  - `test_existing_good_file_is_not_redownloaded`: when the file is present with the right hash, the opener is never called.
  - `test_stream_error_leaves_nothing`: the opener's `read` raises `OSError` mid-stream → `FetchError`, and the dir is empty.
  - `test_cli_fetch_model_prints_path`: `main(["fetch-model", "--out", str(tmp)])`, with `tierwise.fetch.fetch_model` monkeypatched, returns 0 and prints the path.
  - In `tests/router/test_encoder_parity_hf.py`, skipped unless `TIERWISE_HF_ONNX` points at a downloaded file *and* the repo `model.onnx` exists: on 5 fixed sentences, the mean-pooled embeddings from the two files have cosine > 0.999.
